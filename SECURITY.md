# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository instead of opening a public issue. Include the affected version, impact, reproduction steps, and a minimal sanitized log when relevant.

Do not include UU account details, remote device identifiers, IP addresses, display serial numbers, or other private information.

This project uses private macOS display frameworks and reads a local UU Remote log, but it does not make network requests or require administrator privileges. Reports involving unexpected file access, command execution, permission changes, or unsafe brightness recovery are especially useful.
